## Repo Layout
`export_data` contains the final files of the dataset for export.
`generated_data` contains the raw document files in JSON format with rich metadata which can be exported in different ways.
`src` contains the code files to run the data generation pipeline. Many steps have human in the loop to customize the dataset.
`generation_cache` is populated during the data generation process for use between different steps.
`answer_evaluation` is a convenience directory with explanations on how to run eval on your results.

### Export Data
The `export_data` directory contains the final files in .txt format. The files are prefixed with the data set UUID, abreviated as `dsid_`, followed
by a SHA and finally by the actual file name. The file name is just a semantic name generated by the LLM and does not necessarily represent any real
information. The text file contents start with the title of the document followed by all of the content fields identified by the LLM (more on that
later).
